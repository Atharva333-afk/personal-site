# Historical site exports

This directory is the pre-Git record of the personal site. It contains **64 unique HTML exports** recovered from the computer across the `to-know-*`, `atharva-website-*`, and `atharva-living-resume-*` lines of development. Every file has different SHA-256 content; exact duplicates were intentionally omitted.

The live/canonical page is still the root [`index.html`](../../index.html). These exports are preserved snapshots—not deployment copies—and their recovery timestamps do not establish the date an original version was made.

## Archive guide

- [`RELEASE-ARCHIVE.md`](RELEASE-ARCHIVE.md) — detailed 64-entry register, feature audit, lineage map, and verification procedure.
- [`../../RELEASES.md`](../../RELEASES.md) — formal Git-based release history, beginning with the first repository commit.

Use the filenames as evidence of the original working branches. In particular, the numbered suffixes show local iterations within a family, while names such as `with-games`, `with-paint`, and `with-big-questions` identify feature-focused export branches. Do not treat a filename suffix or the November 16, 2026 recovery time as an authoritative original release date.

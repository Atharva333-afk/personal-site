# marki assets

this is the visual side of the build. i kept the original photos and Arduino screenshots because they make the progress way easier to understand than pretending the project appeared fully assembled one day.

## folders

| folder | what is in it |
| --- | --- |
| [build-photos](build-photos/) | ten original hardware photos from the breadboard and board setup |
| [arduino-screenshots](arduino-screenshots/) | ten Arduino IDE screenshots from the upload and debugging path |
| [diagrams](diagrams/) | the architecture and breadboard maps |
| [reference](reference/) | the earlier project image set and starter-kit reference |
| [build-report](build-report/) | the PDF and DOCX build report |

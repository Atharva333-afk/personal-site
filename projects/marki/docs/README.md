# marki docs

this is where the notes go that are way too easy to lose while the hardware is still changing.

the important rule for this folder is simple: if a pin or part was not actually checked, it says so. the project has enough real progress without pretending a photo proves something it does not.

- [circuit wiring and component placement](circuit-wiring.md): the current safe wiring picture and bring-up order.
- [pin map](pin-map.csv): the firmware assignments and the things that still need a physical check.
- [parts and next steps](parts-and-next-steps.md): what has shown up in the build and what needs attention next.
- [verification](verification.md): what the successful ESP32 upload proves and what it does not.
- [build log](build-log.md): the three Lapse entries from the LED, buzzer, and debugging work.
- [build report](build-report/README.md): the full PDF and DOCX archive.

# build report

the full MARKI build archive is included here in both PDF and DOCX form.

it covers the early ESP8266 attempt, the four-digit display direction, the switch to ESP32, the LED and buzzer test setup, the wiring cautions, the photo archive, and the successful upload evidence.

the report is a snapshot of the build at this stage. use the current firmware and wiring notes for the most useful next-step information, especially if the breadboard has been changed since the screenshots were taken.

# Original site source media

These folders contain source media found on the computer that matches sections in the canonical `index.html`:

- `denim/` — original denim collection photos.
- `jerseys/` — original sports-shirt photos.
- `jerseys-cool/` — additional sports/collection graphics.
- `descreened/`, `descreened-2/`, and `descreened-3/` — Descreened project media used to support the portfolio content.

The current site remains self-contained in `index.html`; these files are preserved as source assets for future editing and reconstruction.
